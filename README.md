# FAQ
Модуль добавляет виджет с FAQ и встроенным редактором на любую страницу.  Имеет настройки: - Переключение внешнего вида (Обычный, минималистичный)  - Допускать возможность открытия нескольких пунктов подряд, или нет  Module adds a widget with FAQ and an embedded editor to any page.  Has settings: - Switching the appearance (Normal, Minimalistic) -
