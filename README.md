# FAQ

Модуль добавляет виджет с FAQ и встроенным редактором на любую страницу.

Имеет настройки:
- Переключение внешнего вида (Обычный, минималистичный) 
- Допускать возможность открытия нескольких пунктов подряд, или нет

Module adds a widget with FAQ and an embedded editor to any page.

Has settings:
- Switching the appearance (Normal, Minimalistic)
- Allowing the ability to open multiple items in a row, or not

## Installation

Download the latest release and install it via the Flute CMS admin panel.

Current version: **1.0.5**
